# Bloc Libre

Editor de texto ligero y gratuito desarrollado en Python.

## Características
- Edición de archivos TXT.
- Apertura y extracción de texto de PDF.
- Exportación a PDF.
- Pestañas múltiples.
- Búsqueda y reemplazo.
- Herramientas para unir, dividir, rotar y reorganizar PDF.
- Tema claro y oscuro.

## Instalación desde Python

1. Instalar Python.
2. Descargar este repositorio.
3. Instalar las dependencias:

```bash
py -m pip install -r requirements.txt
```

4. Ejecutar:

```bash
py bloc_libre.py
```
